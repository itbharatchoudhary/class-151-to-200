### platform as a service (PaaS)
- Platform as a Service (PaaS) ek cloud computing ka model hai jisme ek provider developers ko ek complete, managed environment deta hai jahan wo bina underlying infrastructure (jaise servers, storage, network) ki tension liye applications banwa, test, deploy aur manage kar sakte hain

### Infrastructure as a service (IaaS)
- (Infrastructure as a Service) ek cloud computing ka model hai jisme aapko internet ke zariye computing resources jaise servers, storage, networking aur virtual machines rent par milte hain

### Software as a Service (SaaS)
SaaS (Software as a Service) ek cloud computing ka model hai jisme software internet ke zariye ek subscription ke basis par use kiya jata hai, na ki computer par download karke install karne ke liye

### Virtual Private Cloud (VPC)
- ek private network hai jo public cloud ke andar host kiya jata hai.  Isse aap apne cloud resources jaise servers, databases aur applications ko ek secure aur isolated (alag) environment mein launch kar sakte hain.

### Application Load balancer (ALB)
- ALB (Application Load Balancer) ek advanced load balancing service hai jo web traffic ko backend servers (jaise EC2 instances, containers, ya IP addresses) ke beech distribute karta hai.
